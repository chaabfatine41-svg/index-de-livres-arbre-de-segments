# Index de livres avec un arbre de segments
## Description
Ce projet consiste à développer un index de livres en utilisant une structure de données basée sur un arbre de segments.

## Objectifs
- Organiser les informations relatives aux livres.
- Utiliser un arbre de segments pour gérer efficacement les données.
- Comprendre l’application des structures de données dans un système d’indexation.

## Technologies utilisées
- Langage de programmation : à préciser selon l’implémentation.
- Structures de données : arbre de segments.

## Fonctionnalités
- Gestion d’un index de livres.
- Organisation des données.
- Recherche et traitement des informations selon les fonctionnalités implémentées.

Projet académique.
